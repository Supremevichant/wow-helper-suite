## 🧩 About

**World of Warcraft Helper** is a comprehensive utility for WoW featuring overlay menu, HUD widgets, loot tracker, map radar, and config presets for both retail and classic versions.

Based on popular addons like **WeakAuras**, **ElvUI**, and **Details!**.

---

## ✨ Features

### 🎮 Core Utilities
- Overlay Menu — quick access to all helper settings
- HUD Widgets — customisable health, mana, and cast bars
- Loot Tracker — automatic loot logging and statistics
- Map Radar — real-time minimap enhancements and player tracking
- Config Presets — save and load multiple profiles

### 🗺️ Navigation & Info
- Coordinate Display — show precise player coordinates
- Zone Timers — track rare spawns and world quests
- Inventory Scanner — highlight useful items in bags

### 🛠️ Customisation
- Theme Editor — modify overlay colours and fonts
- Hotkey Manager — bind all features to keys
- Profile Export — share configurations with others
